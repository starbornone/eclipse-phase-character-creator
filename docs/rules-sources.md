# Rules sources and content policy

Posthuman Studios licenses Eclipse Phase releases under CC BY-NC-SA 4.0 unless a release says otherwise. The November 2023 *Eclipse Phase Second Edition Quick-Start Rules*, v2.4, carries that licence. The publisher asks for credit to Posthuman Studios, LLC and a link to its site. Our adaptation uses the same licence for the adapted game material, identifies its source and changes, and is intended for noncommercial use. [Publisher licensing policy](https://eclipsephase.com/cclicense/) · [CC BY-NC-SA 4.0 legal code](https://creativecommons.org/licenses/by-nc-sa/4.0/legalcode.en) · [Quick-Start Rules v2.4, credits](https://eclipsephase.com/wp-content/uploads/2024/02/PS10001_EclipsePhaseSecondEdition_QuickStartRulesAcrimony_Nov2023.pdf#page=2)

The app and printed dossier credit the publisher, link to the original and its licence, and identify the data and calculation presentation as an adaptation. The bundled material is limited to selected game terms and stats and original UI prose. The dashboard uses original artwork. The publisher’s logo is a trademark with conditional permission for qualifying fan use. This project uses its own mark. Check each source’s release notice before adding material. [Publisher FAQ on logo use](https://eclipsephase.com/faq/)

For the Quick-Start profiles, store the published health values and their source page. The numbers describe those examples and omit NPC threat pools, equipment, and rules prose. Data lives in [the versioned sample dataset](../src/rules/datasets/sample-morphs.ts). Existing drafts retain their legacy morph names and placeholder durability. The check calculation uses the verified rule for all drafts.
